# LoL Worlds Predictor

Predicting the winner of the League of Legends World Championship using ELO ratings and machine learning.

## Project Overview

Using historical match data, we build a dual ELO system, engineer pre-game features, train machine learning models, and simulate the Worlds tournament.

## Data Source

- Oracle's Elixir: https://oracleselixir.com/tools/downloads

## Tech Stack

- Python (pandas, numpy, scikit-learn, XGBoost)
- Jupyter Notebooks
- Git
